An independent robotics project exploring intuitive human-robot interaction through vision-based hand gesture control of Crazyflie quadrotors. The system began as a real-time single-drone interface and was later extended to multi-drone operation.

Real-time hand gesture perception

I developed a Python-based computer vision pipeline using a standard RGB camera and MediaPipe Hands to track 21 hand landmarks in real time. Hand pose and finger configurations were interpreted as control gestures, enabling direct robot commands without wearable controllers or markers.

Gesture-to-drone control

Recognized gestures were mapped to Crazyflie flight commands through the MotionCommander control framework. A Flow Deck V2 provided time-of-flight altitude sensing, while the control software supported both direct gesture-based flight and preset autonomous motion patterns.

Extension to multi-drone operation

After validating the initial single-drone interface, I extended the system toward coordinated control of multiple quadrotors. This required mapping gesture inputs to multiple robot commands while maintaining responsive perception and stable physical flight.
